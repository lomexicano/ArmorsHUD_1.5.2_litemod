# Ctrl Sprint LiteMod for Minecraft 1.5.2

This is a basic mod that allows sprinting while holding CTRL in Minecraft 1.5.2, similar to vanilla Minecraft 1.8. It also allows sprinting while flying in creative mode.

# Installation
Drop the .litemod file in the mods folder. You must have LiteLoader installed in order to run this mod. 

# Settings
Left Control is the default key for sprinting, but it may be changed in the control settings of the game.
